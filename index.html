ClaudeTool

화면 위를 돌아다니는 Windows용 Claude 데스크톱 펫

펫을 클릭하면 Claude 사용량을, 단축키를 누르면 질문의 답을 말풍선으로 보여 줘요. 캐릭터와 움직임은 설정 창에서 바꿔요.

펫은 늘 다른 창 위에 떠 있어요. 무엇을 하면 어떻게 되는지 모았어요.

설정 › 캐릭터
캐릭터를 고르고 크기(50~200%)·투명도·방향 따라 뒤집기를 정해요. 기본 캐릭터는 이 앱만의 도트 슈크림빵이고, 벡터로 그린 슈크림빵 같은 내장 캐릭터는 카드에 “내장”으로 표시돼요. 캐릭터를 직접 만들고 고치거나 zip으로 가져오고 내보내요.
설정 › 움직임
속도, 활동성, 잠들기까지 시간, 이동 범위(화면 전체·아래쪽 띠·직접 지정), 모니터를 정해요.

화면

동작 방식

펫이 화면 위에 떠 있는 방법부터 사용량, 질문, 캐릭터, 움직임까지 그림으로 정리했어요.

펫 오버레이

펫과 말풍선은 투명한 창 하나에 그려져요. 이 창은 이동 범위에 말풍선 자리를 더한 만큼만 덮고, 늘 맨 위에 있지만 작업 표시줄은 덮지 않아요.

커서가 펫이나 말풍선 위에 있을 때만 클릭을 받고, 빈 자리의 클릭은 아래 창으로 그대로 지나가요. 펫이 떠 있어도 하던 일을 계속할 수 있어요.

사용량

펫을 클릭하면 네 곳의 사용량을 한 창에서 봐요. 소스마다 트레이의 "사용량 소스"에서 켜고 꺼요.

구독 한도는 Claude Code의 statusLine과 연결해서 읽고, 시스템에 Node.js가 있어야 해요. 조직 사용량은 Admin API 키가 필요하고 UTC 기준이에요.

질문

기본은 이 PC에 로그인된 Claude Code를 헤드리스로 실행해(claude -p) 구독으로 답해요. 트레이의 "질문 방식"에서 Anthropic API 키 방식으로 바꿀 수 있어요.

구독 방식은 Claude Code 네이티브 설치(claude.exe)와 로그인이 필요해요. npm으로 설치한 Claude Code(claude.cmd)는 이 앱에서 실행할 수 없어요.

캐릭터

캐릭터는 기본 상태 7개마다 그림을 한 장씩 넣어 만들어요. 오른쪽 재생기는 기본 캐릭터 도트 슈크림빵의 실제 프레임(32×32칸, 모두 23프레임)을 앱처럼 계단식으로 넘겨요. 상태를 누르거나 자동 재생으로 돌려 보세요.

  • 그림 형식: GIF, APNG, WebP, PNG, SVG
  • 그림을 여러 장 끌어다 놓으면 파일 이름으로 자리를 찾아요(walk.gif → 걷기).
  • 새 동작은 12개까지: 빈도, 길이, 제자리·걸으며, 계기(쉬는 중·클릭했을 때·오래 쉬면)
  • zip 가져오기·내보내기: 파일당 10MB, 합계 50MB, 200개까지
  • 데이터 폴더의 packs에 캐릭터 폴더를 넣으면 바로 반영돼요.

움직임 설정

움직임 탭에서 속도, 활동성, 잠들기까지 시간을 정하고 펫이 다닐 범위를 골라요. 모니터가 여럿이면 어느 모니터에서 다닐지도 골라요.

플러그인 틀

개발 중

설치한 플러그인이 펫에 기능을 더하는 틀을 만들고 있어요. 출시본(0.3.0)에는 아직 없고 개발 중이에요. 아래는 설계 내용이라 만들면서 바뀔 수 있어요.

  • 격리 실행설치한 플러그인은 플러그인마다 보이지 않는 샌드박스 창에서 따로 돌아요.
  • 권한 선언과 동의할 수 있는 일을 plugin.json에 선언하고, 설치할 때 보여 주고 동의를 받아요.
  • 네트워크 잠금막힌 프록시와 CSP로 선언하지 않은 주소에는 닿지 못하게 해요.
  • API말풍선, 펫 동작, 저장소, 설정 값을 써요.
  • zip 보관함zip으로 가져오고, 업데이트하고, 지우고, 내보내요.
  • 설정 창 통합설정 창의 플러그인 탭에서 켜고 끄고 설정해요.

개발 방식

Claude Code로 만들었어요. 기능마다 설계와 계획을 먼저 문서로 쓰고, 계획의 태스크마다 서브에이전트 하나가 구현하면 다른 서브에이전트가 리뷰했어요.

  1. 설계
  2. 계획
  3. 태스크별 구현
  4. 다른 에이전트의 리뷰

ClaudeTool 0.3.0

개인 프로젝트이며 Anthropic의 공식 제품이 아니에요. 기본 캐릭터 도트 슈크림빵과 벡터 슈크림빵, 트레이·프로그램 아이콘은 이 프로젝트를 위해 직접 그린 오리지널 그림이에요.
