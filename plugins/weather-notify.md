# 날씨 알림(weather-notify) 안내

도시의 날씨와 초미세먼지를 보고, 비가 올 것 같거나 먼지가 나쁘거나 많이 덥거나 추울 때 하루에 한 번씩, 그리고 아침마다 날씨 요약을 펫이 말풍선과 Windows 알림으로 알려 주는 플러그인입니다. 계정도 키도 필요 없습니다.

## 준비물

- **ClaudeTool 0.4.2 이상**
- **도시 이름 하나.** 한글(`서울`)이나 영어(`Busan`) 모두 됩니다. 기본값은 `Seoul`입니다.
- 인터넷 연결. 날씨는 [Open-Meteo](https://open-meteo.com/)(개인이 쓰는 것은 무료인 날씨 서비스)에서 가져옵니다. 한 번 확인할 때 요청이 2번 가고(도시를 바꾼 직후에는 위치 찾기 1번이 더 갑니다), 기본 간격(60분)이면 하루 50번 안팎, 가장 짧은 간격(30분)이어도 100번 안팎입니다.

## 설치

### ① 플러그인 zip 가져오기

1. [릴리스](https://github.com/BlackBuddle/claude-tool-page/releases/tag/plugins-2026-10)에서 `weather-notify.zip`을 받습니다. 릴리스 노트의 SHA-256 값과 비교해 보세요.
2. ClaudeTool 설정 창 › 🧩 플러그인 › ＋ 가져오기(.zip)로 그 파일을 고릅니다.
3. 동의 창에 아래 줄이 보이는지 확인하고 설치합니다.
   - 말풍선을 띄워요
   - Windows 알림을 띄워요
   - 사용자가 누른 링크를 브라우저로 열어요
   - `https://geocoding-api.open-meteo.com`
   - `https://api.open-meteo.com`
   - `https://air-quality-api.open-meteo.com`

   이 세 주소가 플러그인이 접속하는 곳의 전부입니다. 도시 이름(위치 찾기용)과 그 도시의 좌표(소수점 넷째 자리까지, 예보·대기질 요청용)가 이 서버들로 갑니다. 링크는 말풍선의 [자세히] 버튼을 눌렀을 때만 열립니다.
4. 카드가 "실행 중"이 되면 상세 칸의 "도시 이름"을 내 도시로 바꿉니다. 바꾸면 잠시 뒤 위치를 다시 찾고 곧바로 한 번 확인합니다. 설정 창에서 "위치" 줄에 찾은 도시와 나라가 보이니 맞는지 확인하세요.

### ② 캐릭터 zip 가져오기(선택)

1. 설정 창 › 🐾 캐릭터 › ⤓ 가져오기(.zip)에서 `choux-desk-pack.zip`을 고르고 "사용하기"를 누릅니다.
2. 이 캐릭터를 편집기에서 열어 동작을 더 넣으려면 캐릭터 편집기 화면의 "동작 한도" 칸을 37 이상(예: 40, 최대 60)으로 올려 주세요(기본은 12개이고, 이 캐릭터는 동작이 36개라 36으로는 새 동작을 더할 수 없습니다). 열기·저장·사용은 올리지 않아도 됩니다.

캐릭터가 없어도 말풍선과 Windows 알림은 옵니다. 다른 캐릭터에는 이 플러그인용 몸짓이 없어서 몸짓만 빠집니다.

### ③ 설정 칸

| 칸 | 기본값 | 뜻 |
|---|---|---|
| 도시 이름 | `Seoul` | 날씨를 볼 도시. 한글·영어 모두 됩니다 |
| 비 알림 기준(강수 확률 %) | 60 | 오늘 하루 중 강수 확률의 최댓값이 이 값 이상이면 비 알림(10~100) |
| 더위 알림 기준(최고 기온 °C 이상) | 33 | 오늘 최고 기온이 이 값 이상이면 더위 알림(20~45) |
| 추위 알림 기준(최저 기온 °C 이하) | -10 | 오늘 최저 기온이 이 값 이하이면 추위 알림(-30~10) |
| 미세먼지 알림 기준(PM2.5 ㎍/㎥ 이상) | 36 | 지금 시각의 초미세먼지가 이 값 이상이면 미세먼지 알림(10~150). 36이 한국 기준의 "나쁨" 시작입니다 |
| 아침 요약 시각 | 7 | 몇 시 이후 첫 확인에 날씨 요약을 알릴지(0~23시, 그 도시의 현지 시각) |
| 확인 간격(분) | 60 | 날씨를 다시 가져오는 간격(30~360) |
| [자세히] 주소 | `https://open-meteo.com/` | 아침 요약 말풍선의 버튼이 여는 주소. https만 됩니다(다른 날씨 사이트 주소로 바꿀 수 있습니다) |
| 비 알림 · 미세먼지 알림 · 더위·추위 알림 · 아침 날씨 요약 | 켬 | 종류별로 끄기 |
| Windows 알림도 띄우기 | 켬 | 끄면 말풍선과 펫 몸짓만 |
| 방해 금지 시작·끝(HH:MM) | (비어 있음) | 둘 다 적으면 그 시간에는 알리지 않고 모아 두었다가 끝나면 한 번에 알립니다. `22:00`~`07:00`처럼 자정을 넘겨도 됩니다. 한쪽만 적거나 형식이 틀리면 꺼 두고 설정 창에 이유가 보입니다 |

설정 창 안에는 마지막으로 확인한 시각, 위치, 오늘 날씨 요약, 최근 소식이 보이고 [지금 확인] 버튼이 있습니다. 기준값이나 도시를 바꾸면 잠시 뒤 새 설정으로 한 번 다시 확인합니다.

## 알림 종류와 펫 동작

| 종류 | 언제 | 말풍선 | 펫 동작(`choux-desk`) |
|---|---|---|---|
| 비 소식(`rain`) | 오늘 강수 확률이 기준 이상, 하루 한 번 | "오늘 비 올 확률이 70%예요. 우산을 챙기세요." | `wx_rain`(우산 배지와 빗방울) |
| 미세먼지(`dust`) | 지금 시각의 초미세먼지가 기준 이상, 하루 한 번 | "초미세먼지(PM2.5)가 40㎍/㎥로 '나쁨'이에요. 마스크를 챙기세요." | `wx_dust`(마스크 배지와 회색 먼지) |
| 더위·추위(`extreme`) | 오늘 최고 기온이 더위 기준 이상이거나 최저 기온이 추위 기준 이하, 하루 한 번 | "오늘 최고 34°C까지 올라요. 더위에 조심하고 물을 자주 마셔요." / "오늘 최저 -12°C까지 내려가요. 따뜻하게 입고 나가요." | `wx_extreme`(온도계 배지, 화면이 빨갛게 번쩍) |
| 아침 날씨(`morning`) | 아침 요약 시각이 지난 첫 확인, 하루 한 번 | 날씨 요약과 [자세히] 버튼. 예: "[서울] 오늘은 흐림. 기온 12~21°C, 비 올 확률 30%, 초미세먼지 22㎍/㎥(보통), 미세먼지 41㎍/㎥." | `wx_morning`(해와 구름 배지) |

- 같은 종류는 그 도시의 하루(자정에서 자정까지)에 한 번만 알립니다. 오후에 상황이 바뀌어도 같은 날 같은 종류를 다시 알리지 않습니다. PC를 껐다 켜도 마찬가지입니다.
- 미세먼지만은 예외로, 그날 나쁨 알림을 보낸 뒤 기준 아래로 내려오면 "초미세먼지가 20㎍/㎥(보통)로 좋아졌어요." 하는 짧은 말풍선을 한 번 보냅니다. 이 소식에는 펫 몸짓과 Windows 알림이 없습니다. 자정이 지나기 전에 풀리지 않으면 보내지 않습니다.
- 한 번에 여러 종류가 걸리면 비, 미세먼지, 더위·추위, 아침 요약 순서로 알립니다. 짧은 사이에 세 건 이상이면 말풍선이 하나의 목록으로 합쳐질 수 있습니다.
- 플러그인을 처음 켠 직후의 첫 확인에서도, 이미 걸려 있는 조건(오늘 비 확률이 높다 등)은 바로 알립니다.

## 한계

- 한 번에 **도시 하나**만 봅니다. 같은 이름의 도시가 여럿이면 서비스가 첫 번째로 찾은 곳을 씁니다. 엉뚱한 곳이면 영어 이름이나 더 널리 알려진 도시 이름으로 바꿔 보세요.
- **오늘 날씨만** 봅니다. 내일 예보를 미리 알리지는 않습니다.
- 강수 확률은 "오늘 하루 중 가장 높은 값"입니다. 오전에 한 번 높게 나왔다가 낮에는 갠다고 해도 비 알림이 올 수 있습니다.
- 예보에 강수 확률이 없는 지역에서는 비 알림이 오지 않고, 아침 요약에서도 그 부분이 빠집니다.
- 날씨는 Open-Meteo가 기상 모델로 계산한 값이라 기상청 발표와 다를 수 있습니다. 미세먼지는 관측소에서 잰 값이 아니라 대기 모델(격자) 계산값이라 에어코리아 발표와 차이가 날 수 있습니다. 참고용으로 봐 주세요.
- 앱이 꺼져 있거나 PC가 잠자기 중인 동안은 확인하지 않습니다. 다시 켜면 밀린 확인을 한 번 하고, 아침 요약은 요약 시각이 지났으면 그때 바로 알립니다.
- 무료 서비스(비상업적 개인 용도) 기준으로 만들었습니다. 확인 간격을 아주 짧게 두거나 여러 대에서 한꺼번에 쓰면 서비스의 호출 한도에 걸릴 수 있습니다. 그때는 알림 없이 간격을 늘려 자동으로 다시 시도합니다.
- 미세먼지(PM2.5)만 알립니다. PM10은 아침 요약에 숫자로만 나옵니다.

## 문제 해결

| 증상 | 이유와 해결 |
|---|---|
| 설정 창에 "설정에서 도시 이름을 적어 주세요" | 도시 칸이 비어 있습니다. 도시 이름을 적으세요 |
| "\"…\" 도시를 찾지 못했어요" | 서비스가 그 이름을 모릅니다. 철자를 확인하거나 영어 이름(예: `Busan`)으로 적어 보세요 |
| "예보를 읽지 못했어요" | 서버가 날씨 대신 오류를 돌려줬습니다. 잠시 뒤 [지금 확인]을 눌러 보고, 계속되면 도시 이름을 바꿔 보세요 |
| "잠시 뒤 다시 시도해요(HTTP 429/5xx)"나 "서버에 연결하지 못했어요" | 서버가 바쁘거나 호출 한도에 걸렸거나 인터넷이 끊겼습니다. 알림 없이 간격을 늘려 자동으로 다시 시도하고, 되돌아오면 지웁니다. 미세먼지 정보만 못 받은 경우에는 비·더위·추위·아침 요약은 그대로 오고 미세먼지 알림만 빠집니다 |
| 앱 로그(`logs\plugins.log`)에 "요청이 거절됐어요" | 요청 주소가 위 세 곳이 아닙니다. 이 세 곳의 주소만 쓸 수 있습니다 |
| 다른 도시의 날씨가 와요 | 설정 창의 "위치" 줄에서 찾은 도시를 확인하세요. 영어 이름으로 바꾸거나 더 큰 도시 이름을 적어 보세요 |
| 알림이 안 와요 | ① 조건이 걸렸는지(기준값보다 낮으면 오지 않습니다. 설정 창의 오늘 요약과 비교해 보세요) ② 오늘 이미 알린 종류는 아닌지(같은 종류는 하루 한 번입니다) ③ 종류를 끄지 않았는지 ④ 방해 금지 시간이 아닌지(설정 창에 모인 소식 수가 보입니다) ⑤ 펫을 숨겨 두지 않았는지(숨기면 말풍선은 못 뜨고 Windows 알림만 옵니다) ⑥ Windows의 "방해 금지"·집중 지원이 알림을 막고 있지 않은지 확인하세요 |
| 아침 요약이 안 와요 | 요약 시각이 지난 뒤의 첫 확인에 옵니다(확인 간격이 60분이면 시각에서 최대 한 시간쯤 늦을 수 있습니다). 예보를 받지 못한 날에는 오지 않고, "아침 날씨 요약" 칸이 꺼져 있어도 오지 않습니다 |
| 요약 시각이 어긋나요 | 아침 요약 시각은 이 PC의 시각이 아니라 설정한 도시의 현지 시각입니다 |
