# 캘린더 알림(cal-notify) 안내

구글·아웃룩 캘린더의 iCal 주소를 읽어서, 일정이 곧 시작하거나 시작할 때, 그리고 아침마다 오늘 일정을 펫이 말풍선과 Windows 알림으로 알려 주는 플러그인입니다. 캘린더에 로그인하지 않고, 읽기만 합니다.

## 준비물

- **ClaudeTool 0.4.2 이상**
- **캘린더의 iCal 비공개 주소.** 알림을 받을 캘린더마다 주소가 따로 있고, 이 플러그인은 주소 하나(캘린더 하나)를 읽습니다. 주소를 아는 사람은 로그인 없이 그 캘린더를 읽을 수 있으니 남에게 알려 주지 마세요. 아래 예시는 모양만 보이는 가짜 값입니다.

  `https://calendar.google.com/calendar/ical/example%40gmail.com/private-00000000000000000000000000000000/basic.ics`

### 구글 캘린더에서 주소 얻기

1. 컴퓨터 브라우저로 `calendar.google.com`에 들어갑니다(휴대폰 앱에서는 주소를 볼 수 없습니다).
2. 오른쪽 위 톱니바퀴 › 설정을 엽니다.
3. 왼쪽의 "내 캘린더 설정"에서 알림 받을 캘린더를 고르고 "캘린더 통합"으로 내려갑니다.
4. "iCal 형식의 비공개 주소"를 복사합니다. 주소가 새어 나갔다면 같은 자리의 "주소 재설정"으로 새로 만들 수 있고, 그러면 옛 주소는 쓸 수 없게 됩니다.

### 아웃룩 캘린더에서 주소 얻기

1. `outlook.office365.com` 또는 `outlook.live.com`의 웹 아웃룩에서 설정 › 캘린더 › 공유 캘린더로 갑니다.
2. "캘린더 게시"에서 캘린더를 고르고 권한을 "모든 세부 정보 확인 가능"으로 정한 뒤 게시합니다.
3. 나타나는 **ICS 링크**를 복사합니다(HTML 링크가 아닙니다). 게시를 취소하면 그 주소는 쓸 수 없게 됩니다.

회사·학교 계정은 관리자가 게시를 막아 두었을 수 있습니다. 그때는 이 플러그인을 쓸 수 없습니다.

## 설치

### ① 플러그인 zip 가져오기

1. [릴리스](https://github.com/BlackBuddle/claude-tool-page/releases/tag/plugins-2026-10)에서 `cal-notify.zip`을 받습니다. 릴리스 노트의 SHA-256 값과 비교해 보세요.
2. ClaudeTool 설정 창 › 🧩 플러그인 › ＋ 가져오기(.zip)로 그 파일을 고릅니다.
3. 동의 창에 아래 줄이 보이는지 확인하고 설치합니다.
   - 말풍선을 띄워요
   - Windows 알림을 띄워요
   - 사용자가 누른 링크를 브라우저로 열어요
   - `https://calendar.google.com`
   - `https://outlook.office365.com`
   - `https://outlook.live.com`

   이 세 주소가 플러그인이 접속하는 곳의 전부입니다. 링크는 말풍선의 [캘린더 열기] 버튼을 눌렀을 때만 열립니다.
4. 카드가 "실행 중"이 되면 상세 칸의 "iCal 비공개 주소" 칸에 복사한 주소를 붙여 넣습니다. 이 칸은 비밀 칸이라 저장한 뒤에는 값이 다시 보이지 않고, 앱의 안전 저장소에만 둡니다. `webcal://`로 시작하는 주소를 붙여 넣어도 됩니다(`https`로 바꿔 읽습니다).

### ② 캐릭터 zip 가져오기(선택)

1. 설정 창 › 🐾 캐릭터 › ⤓ 가져오기(.zip)에서 `choux-desk-pack.zip`을 고르고 "사용하기"를 누릅니다.
2. 이 캐릭터를 편집기에서 열어 동작을 더 넣으려면 캐릭터 편집기 화면의 "동작 한도" 칸을 37 이상(예: 40, 최대 60)으로 올려 주세요(기본은 12개이고, 이 캐릭터는 동작이 36개라 36으로는 새 동작을 더할 수 없습니다). 열기·저장·사용은 올리지 않아도 됩니다.

캐릭터가 없어도 말풍선과 Windows 알림은 옵니다. 다른 캐릭터에는 이 플러그인용 몸짓이 없어서 몸짓만 빠집니다.

### ③ 설정 칸

| 칸 | 기본값 | 뜻 |
|---|---|---|
| iCal 비공개 주소 | (비어 있음) | 위에서 복사한 주소 |
| 확인 간격(분) | 15 | 캘린더를 다시 가져오는 간격(5~120). 알림 시각은 이 간격과 상관없이 맞춰서 울립니다 |
| 미리 알림(분) | 10 | 시작 몇 분 전부터 "곧 일정"을 알릴지(1~120) |
| 아침 요약 시각 | 8 | 몇 시 이후에 오늘 일정 요약을 알릴지(0~23시) |
| [캘린더 열기] 주소 | `https://calendar.google.com/` | 아침 요약 말풍선의 버튼이 여는 주소. https만 됩니다(아웃룩이면 `https://outlook.office.com/calendar/`처럼 바꾸세요) |
| 곧 일정 알림 · 시작 알림 · 아침 요약 | 켬 | 종류별로 끄기 |
| Windows 알림도 띄우기 | 켬 | 끄면 말풍선과 펫 몸짓만 |
| 방해 금지 시작·끝(HH:MM) | (비어 있음) | 둘 다 적으면 그 시간에는 알리지 않고 모아 두었다가 끝나면 한 번에 알립니다. `22:00`~`07:00`처럼 자정을 넘겨도 됩니다. 한쪽만 적거나 형식이 틀리면 꺼 두고 설정 창에 이유가 보입니다 |

설정 창 안에는 마지막으로 확인한 시각, 다음 일정, 최근 소식이 보이고 [지금 확인] 버튼이 있습니다.

## 알림 종류와 펫 동작

| 종류 | 언제 | 말풍선 | 펫 동작(`choux-desk`) |
|---|---|---|---|
| 곧 일정(`soon`) | 시작 `미리 알림`분 전부터 시작 전까지, 일정마다 한 번 | "10분 뒤 14:00 팀 회의" | `cal_soon`(시계 배지) |
| 일정 시작(`now`) | 시작 시각부터 5분 안, 일정마다 한 번 | "지금 시작: 14:00 팀 회의" | `cal_now`(달력 배지와 반짝임) |
| 아침 일정(`morning`) | `아침 요약 시각`이 지난 뒤 하루 한 번 | "오늘 일정 N건"과 시각·제목 최대 8줄(넘으면 "…외 N건"), [캘린더 열기] 버튼. 종일 일정이 먼저 나옵니다 | `cal_morning`(해 배지) |

- 종일 일정(생일·휴가 등)은 시작 알림이 없고 아침 요약에만 나옵니다.
- 오늘 일정이 없으면 "오늘 일정이 없어요"라고 말풍선만 짧게 띄웁니다(Windows 알림은 없습니다).
- 같은 일정은 PC를 껐다 켜도 같은 시작 시각에 두 번 알리지 않습니다. 반복 일정은 회차마다 따로 셉니다.

## 한계

- **앞으로 48시간 안의 일정만** 봅니다. 알림은 그 안에서 울립니다.
- 앱이 꺼져 있거나 PC가 잠자기 중인 동안의 알림은 울리지 않습니다. 다시 켰을 때 시작한 지 5분이 안 지난 일정만 "시작"으로 알리고, 더 지난 일정은 조용히 넘어갑니다. 아침 요약은 그 날 처음 확인했을 때, 요약 시각이 지났으면 바로 알립니다.
- 캘린더 하나(주소 하나)만 읽습니다. 여러 캘린더를 함께 알리는 기능은 아직 없으니, 알림이 가장 필요한 캘린더를 고르세요.
- 구글·아웃룩 주소만 읽습니다. 다른 서비스(네이버·카카오 등)의 주소는 접속이 막혀 쓸 수 없습니다.
- 반복 규칙은 매일·매주·매달·매년과 요일·몇째 주·말일·횟수·끝나는 날·제외한 날·바뀐 회차를 지원합니다. 시간·분 단위 반복이나 "각 달의 마지막 평일" 같은 복잡한 규칙은 첫 일정만 알립니다.
- 일정에 붙은 캘린더 쪽 알림 설정(10분 전 팝업 등)은 읽지 않습니다. 알림 시각은 이 플러그인의 설정을 따릅니다.
- 서비스가 주소의 내용을 늦게 고치는 경우가 있어서, 방금 만든 일정이 몇 분에서 몇 시간 뒤에야 보일 수 있습니다.
- 한 번에 가져오는 캘린더는 5MB까지입니다.

## 문제 해결

| 증상 | 이유와 해결 |
|---|---|
| 설정 창에 "설정에서 iCal 비공개 주소를 넣어 주세요" | 주소 칸이 비어 있습니다. 위 "주소 얻기"대로 복사해 붙여 넣으세요 |
| "iCal 주소는 https:// 로 시작해야 해요" | `http`로 시작하는 주소나 일반 웹 주소를 넣었습니다. `https`(또는 `webcal`)로 시작하는 ICS 주소가 필요합니다 |
| "설정을 확인해 주세요(키나 토큰이 거절됐어요, HTTP 401/403)" | 주소가 재설정됐거나 게시가 취소됐습니다. 새 주소를 받아 붙여 넣으세요. 한 번만 말풍선으로 알리고 설정 창에는 계속 보입니다 |
| "캘린더 데이터를 읽지 못했어요: …" | 주소가 ICS 파일이 아니라 로그인 화면 같은 웹 페이지를 가리킵니다. 주소를 다시 복사하세요(구글은 "iCal 형식의 비공개 주소", 아웃룩은 HTML이 아닌 ICS 링크). 이 상태에서는 이전에 가져온 일정을 그대로 두고, 마지막으로 잘 가져온 지 3시간 안이면 그 일정으로 계속 알립니다(3시간이 넘으면 아침 요약만 미룹니다) |
| "주소가 바뀌었거나 게시가 취소됐을 수 있어요(HTTP 404)" 같은 줄 | 서버가 일정 대신 오류(404·410 등)로 답했습니다. 주소를 재설정했거나 게시를 취소했다면 새 주소를 받아 붙여 넣으세요. 이전에 가져온 일정은 그대로 두고 3시간 안이면 알림도 계속됩니다 |
| "이 주소는 접속할 수 없어요(구글·아웃룩 주소만 쓸 수 있어요)" | 주소의 서버가 `calendar.google.com`·`outlook.office365.com`·`outlook.live.com`이 아닙니다(iCloud·네이버 캘린더 등은 지원하지 않습니다). 설정 창에도 같은 안내가 보입니다 |
| "잠시 뒤 다시 시도해요(HTTP 429/5xx)"나 "서버에 연결하지 못했어요" | 서버가 바쁘거나 인터넷이 끊겼습니다. 알림 없이 간격을 늘려 자동으로 다시 시도하고, 되돌아오면 지웁니다 |
| 앱 로그(`logs\plugins.log`)에 "요청이 거절됐어요" | 위 "이 주소는 접속할 수 없어요"와 같은 이유입니다. 이 세 곳의 주소만 쓸 수 있습니다 |
| 알림이 안 와요 | ① 종류를 끄지 않았는지 ② 방해 금지 시간이 아닌지(설정 창에 모인 소식 수가 보입니다) ③ 펫을 숨겨 두지 않았는지(숨기면 말풍선은 못 뜨고 Windows 알림만 옵니다) ④ Windows의 "방해 금지"·집중 지원이 알림을 막고 있지 않은지 확인하세요 |
| 일정 시각이 몇 시간 어긋나요 | 일정에 쓰인 시간대 이름을 이 플러그인이 모르면 UTC로 읽고 앱 로그에 "모르는 시간대(…)라서 UTC로 읽었어요"를 남깁니다. 캘린더 쪽 시간대를 `Asia/Seoul`처럼 흔한 이름으로 바꿔 보세요 |
| 방금 만든 일정이 안 보여요 | [지금 확인]을 눌러 보세요. 그래도 안 보이면 서비스가 주소 내용을 아직 고치지 않은 것입니다 |
