# 유튜브 검색·새 영상(yt-search) 안내

펫에게 유튜브 검색을 시키고, 구독한 채널에 새 영상이 올라오면 말풍선으로 알려 주는 플러그인입니다. 검색 결과는 말풍선에 5줄로 보이고, 영상은 말풍선의 [열기] 버튼을 눌러야 브라우저에서 열립니다.

## 준비물

- **ClaudeTool 0.4.2 이상.** 이 플러그인은 0.4.2에서 생긴 권한 가운데 `open-link`(사용자가 누른 링크 열기)를 씁니다.
- **YouTube API 키(무료).** 검색에 필요합니다. 새 영상 알림만 쓰고 채널을 id(`UC…`)로 적으면 키가 없어도 됩니다.
- **zip 파일 두 개:** 플러그인 `yt-search.zip`과 캐릭터 `choux-desk-pack.zip`을 [릴리스](https://github.com/BlackBuddle/claude-tool-page/releases/tag/plugins-2026-10)에서 받습니다(릴리스 노트의 SHA-256 값과 비교해 보세요.). 캐릭터는 없어도 알림과 검색은 됩니다.

### API 키 만들기

1. Google 계정으로 Google Cloud 콘솔(`console.cloud.google.com`)에 로그인하고, 위쪽 프로젝트 목록에서 **새 프로젝트**를 만듭니다. 이름은 아무거나 괜찮습니다(예: `claudetool-youtube`).
2. 왼쪽 메뉴 **API 및 서비스 › 라이브러리**에서 `YouTube Data API v3`를 찾아 **사용**을 누릅니다.
3. **API 및 서비스 › 사용자 인증 정보 › 사용자 인증 정보 만들기 › API 키**를 누르면 키가 만들어집니다. 복사해 둡니다.
4. 권장: 만든 키의 **키 제한**에서 API 제한을 `YouTube Data API v3` 하나로 좁힙니다. 키가 새어도 다른 곳에 쓰이지 않습니다.
5. 하루 한도: **검색은 하루 약 100회**입니다(검색만 따로 세는 한도). 채널 확인 같은 나머지 요청은 따로 하루 10,000 단위인데 이 플러그인은 거의 쓰지 않습니다. 한도는 매일 새로 채워집니다.

키는 비밀입니다. 남에게 보이지 말고, 문서나 채팅에 붙여 넣지 마세요. 이 안내서의 예시는 모두 가짜 값입니다.

## 설치

### ① 플러그인 zip 가져오기

1. ClaudeTool 설정 창 › 🧩 플러그인 › ＋ 가져오기(.zip)를 눌러 `yt-search.zip`을 고릅니다.
2. 동의 창이 뜹니다. `"유튜브 검색" 1.0.0을 설치할까요?` 아래에 다음 줄이 보이는지 확인하고, 괜찮으면 **설치**를 누릅니다.
   - 이 플러그인이 할 수 있는 일: 말풍선을 띄워요 / 따로 뜨는 창을 열어요 / 사용자가 누른 링크를 브라우저로 열어요
   - 접속할 주소: `https://www.googleapis.com`(검색·채널 확인) / `https://www.youtube.com`(새 영상 목록·채널 페이지) / `https://i.ytimg.com`(검색 창의 작은 그림)
   - 비밀 값(API 키 등)을 받는 칸이 1개 있어요. 이 플러그인은 그 값을 읽어요.
3. 카드가 "실행 중"이 되면 끝입니다.

링크는 플러그인이 마음대로 열지 못합니다. 말풍선의 [열기] 버튼을 **사용자가 눌렀을 때만** 앱이 브라우저로 엽니다. 알림(`notify`)·펫 직접 조작·클립보드 권한은 쓰지 않습니다.

### ② 캐릭터 zip 가져오기(선택)

1. 설정 창 › 🐾 캐릭터 › ⤓ 가져오기(.zip)를 눌러 `choux-desk-pack.zip`을 고릅니다.
2. 가져온 캐릭터 카드에서 **사용하기**를 누르면 이 플러그인의 네 가지 신호에 맞는 몸짓(아래 표)이 나옵니다. 다른 캐릭터에는 이 몸짓이 없어서 말풍선만 쓰입니다.
3. 이 캐릭터는 동작이 36개입니다. 캐릭터 편집기 화면에서 **동작을 더하려면** 같은 화면의 **"동작 한도"** 칸을 37 이상(예: 40, 최대 60)으로 올리세요(한도가 36이면 새 동작을 더할 수 없습니다). 열기·저장·사용은 올리지 않아도 됩니다.

### ③ 설정 칸

설정 창 › 🧩 플러그인에서 `유튜브 검색` 카드를 고르면 아래 상세 칸에 설정이 보입니다. 키 칸은 **바꾸기**를 누르면 가려진 입력칸이 나오고, **저장**(또는 Enter)으로 보냅니다. 저장된 키는 화면에 다시 보이지 않습니다.

| 칸 | 기본값 | 설명 |
|---|---|---|
| YouTube API 키 | 없음 | 검색에 필요합니다. 위 "API 키 만들기"에서 만든 키 |
| 구독 채널 | 빈 칸 | 줄마다 하나씩, 20개까지. 아래 "채널 적는 법" |
| 새 영상 확인 간격(분) | 30 | 10~360. 간격마다 구독 채널의 새 영상 목록을 읽습니다 |
| 검색 결과 개수 | 5 | 1~5 |
| 방해 금지 시작·끝 | 빈 칸 | `22:00`·`07:00`처럼 적으면 그 시간에는 새 영상을 알리지 않고 목록에만 모읍니다(자정을 넘겨도 됩니다). 둘 중 하나만 적으면 꺼집니다 |
| 검색 중 펫 반응 | 켬 | 검색하는 동안 펫이 보이는 몸짓 |
| 영상을 찾으면 알림 | 켬 | 찾았을 때 펫 몸짓과 결과 말풍선. 꺼도 검색 창의 목록은 그대로 보입니다 |
| 못 찾으면 알림 | 켬 | 결과가 없을 때 펫 몸짓과 말풍선 |
| 구독 채널 새 영상 알림 | 켬 | 새 영상 말풍선 |

**채널 적는 법.** 아래 어느 모양이든 한 줄에 하나씩 적습니다(예시는 가짜 값입니다).

```
UC0000000000000000000000
@example_channel
https://www.youtube.com/@example_channel
https://www.youtube.com/channel/UC0000000000000000000000
https://www.youtube.com/c/example
```

- 채널 id(`UC`로 시작하는 24자)가 가장 확실하고 키가 필요 없습니다. 유튜브 웹의 채널 페이지에서 채널 설명 › 채널 공유 › 채널 ID 복사로 얻습니다(메뉴 이름은 화면에 따라 다를 수 있습니다).
- `@핸들`은 API 키로 채널 id를 찾아 씁니다. 키가 없으면 찾지 못합니다.
- `/c/이름`·`/user/이름` 주소는 그 채널 페이지를 읽어 id를 찾습니다. 유튜브 페이지 모양이 바뀌면 못 찾을 수 있으니, 안 되면 채널 id를 적으세요.
- 읽을 수 없는 줄, 겹친 줄, 20개를 넘은 줄은 건너뜁니다. 몇 개를 건너뛰었는지는 설정 창 안 화면의 요약 줄에 보입니다.

### ④ 써 보기

1. 설정 창 안 화면에서 **검색 창 열기**를 누르면 따로 뜨는 창이 열립니다.
2. 검색어를 넣고 Enter(또는 [검색])를 누릅니다. 펫이 검색 몸짓을 하고, 결과가 창의 목록과 말풍선에 나옵니다.
3. 말풍선의 **[1 열기]…[5 열기]**를 누르면 그 영상이 브라우저에서 열립니다. 말풍선은 60초 뒤 저절로 닫히며, 창의 **말풍선에 다시 띄우기**로 다시 볼 수 있습니다.
4. 구독 채널은 설정 창 안 화면의 **지금 확인**으로 바로 읽어 볼 수 있습니다.

창에는 최근 검색 10개가 보이고, 누르면 다시 검색합니다. 최근 검색어는 이 PC의 파일에 저장하지 않아서 플러그인을 다시 시작하면 지워집니다. 영상마다 작은 그림(썸네일)이 함께 보이는데, 이 환경에서 그림을 받지 못하면 글만 보입니다.

## 알림 종류와 펫 동작

| 알림 | 언제 | 말풍선 | 캐릭터 동작(choux-desk) |
|---|---|---|---|
| 검색 중 | 검색을 보낸 직후 | 없음 | 검색 중(돋보기) |
| 영상 찾음 | 결과가 1건 이상 | 결과 5줄 + [N 열기] | 영상 찾음(재생 표시, 반짝임) |
| 못 찾음 | 결과가 0건 | 짧은 글 | 못 찾음(가위표) |
| 새 영상 | 구독 채널에 새 영상 | 채널·제목 + [열기] | 새 영상(재생 표시와 종) |

- **새 영상은 처음 확인할 때 알리지 않습니다.** 채널을 처음 넣은 뒤 첫 확인에서는 지금 올라와 있는 영상을 "이미 본 것"으로 기억만 하고, 그 뒤에 올라온 영상부터 알립니다. 채널마다 최근 20개를 기억합니다.
- 앱이나 플러그인이 꺼져 있는 동안 올라온 영상은, 채널의 최근 목록(보통 15개)에 남아 있으면 다시 켠 뒤 첫 확인에서 알립니다.
- 채널 하나당 한 번의 확인에서 알리는 새 영상은 가장 새로운 8개까지입니다. 여럿이면 한 말풍선에 목록으로 합쳐 보입니다.
- 검색은 직접 시킨 일이라 방해 금지 시간에도 결과가 나옵니다.

## 한계

- **검색은 하루 약 100회**입니다. 넘으면 "오늘 검색 한도"라고 알리고 다음 날까지 검색되지 않습니다. 새 영상 알림은 검색 한도를 쓰지 않습니다.
- **영상은 말풍선의 [열기] 버튼으로만 열립니다.** 검색 창의 목록에는 열기 버튼이 없습니다(앱 규칙). 말풍선이 닫혔으면 [말풍선에 다시 띄우기]를 쓰세요.
- 이 플러그인은 Windows 알림 권한을 쓰지 않습니다. 펫이 숨겨져 있으면 새 영상 소식이 보이지 않고 설정 창 안 화면의 최근 소식에만 남습니다.
- 말풍선은 분당 10개까지라, 소식이 한꺼번에 몰리면 일부는 잠시 뒤 "N건 더" 말풍선으로 합쳐 알립니다.
- 영상 길이·조회수는 보이지 않습니다. 제목·채널·올린 날짜만 보입니다.
- 채널은 20개까지, 새 영상 확인 간격은 10분 이상입니다. 간격 사이에 한 채널이 15개를 넘게 올리면 그 가운데 일부는 놓칩니다.
- 검색어와 API 키는 유튜브(Google)로 보내집니다. 키는 Windows 안전 저장소에 암호화해 두고 로그·화면에 남기지 않습니다.
- 말로 묻는 자연어 검색은 이 판에 없습니다.

## 문제 해결

| 증상 | 이유와 해결 |
|---|---|
| "검색하려면 API 키가 필요해요" | 설정의 "YouTube API 키"에 키를 넣으세요. |
| "API 키 모양이 올바르지 않아요" | 키에 공백·한글이 섞였거나 잘렸습니다. 다시 복사해 넣으세요. 키는 영문·숫자·`-`·`_`로만 이뤄집니다. |
| "API 키를 확인해 주세요…" | 키가 틀렸거나, 키 제한이 `YouTube Data API v3`를 막고 있을 수 있습니다. 콘솔의 사용자 인증 정보에서 확인하세요. |
| "Google Cloud에서 YouTube Data API v3를 사용 설정했는지 확인해 주세요" | 만든 프로젝트에서 라이브러리의 `YouTube Data API v3`를 **사용**으로 바꾸세요(키를 만든 프로젝트와 같아야 합니다). |
| "오늘 검색 한도(하루 약 100회)를 다 썼어요" | 검색은 하루 약 100회입니다. 한도가 다시 채워지길 기다리세요. |
| "검색이 너무 잦아요" | 잠시 뒤 다시 검색하세요. |
| 검색은 됐는데 말풍선이 안 뜸 | 펫을 숨겼거나 다른 창이 말풍선을 쓰는 중입니다. 검색 창의 목록은 보이니, 펫을 다시 보이게 한 뒤 [말풍선에 다시 띄우기]를 누르세요. |
| 새 영상 알림이 안 옴 | ① 채널을 처음 넣은 뒤 첫 확인은 알리지 않습니다. ② 설정 창 안 화면의 요약 줄에서 "찾지 못한 채널"이나 "못 읽은 줄"이 있는지 보세요. ③ 방해 금지 시간이거나 "구독 채널 새 영상 알림"이 꺼져 있지 않은지 보세요. ④ 확인 간격이 긴지 보세요. [지금 확인]으로 바로 읽어 볼 수 있습니다. |
| "찾지 못한 채널 N개" | 주소 모양을 확인하거나 채널 id(`UC…`)로 적어 보세요. 없는 채널이면 건너뜁니다. @핸들이라면 API 키가 틀려도 이렇게 보이니, 뒤에 "API 키를 확인해 주세요"가 붙었는지 보고 검색 창에서 키 오류를 확인하세요. |
| "API 키가 없어 @핸들 N개를 못 찾았어요" | 키를 넣거나, 그 채널을 채널 id로 적으세요. |
| 설정 창 안 화면에 "설정을 확인해 주세요" | API 키가 거절됐습니다(키가 틀려도 @핸들 조회는 이 문구 대신 요약 줄의 "API 키를 확인해 주세요"로 보입니다). 위 "API 키를 확인해 주세요"를 보세요. |
| 검색 창에 작은 그림이 없음 | 이 환경에서 그림을 받지 못하면 글만 보이는 것이 정상입니다. 검색과 열기에는 영향이 없습니다. |
| 설정 창 안 화면이 비어 있음 | 플러그인이 "실행 중"일 때만 보입니다. 카드가 꺼져 있으면 켜세요. |
