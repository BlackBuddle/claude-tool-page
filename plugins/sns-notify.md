# SNS 알림(sns-notify) 안내

Instagram·Threads에서 좋아요, 댓글, 새 팔로워, 메시지(DM), 언급이 오면 펫이 말풍선과 Windows 알림으로 알려 주는 플러그인입니다. 소식을 받는 길이 둘입니다.

- **폰 알림 전달(기본, 안드로이드만)**: 폰에 뜬 Instagram·Threads 알림 글을 폰의 MacroDroid 앱이 [ntfy](https://ntfy.sh/)(알림 글을 중계해 주는 무료 공개 서비스)로 보내고, 이 플러그인이 그 글을 받습니다. 계정 로그인도 키 발급도 필요 없습니다.
- **Meta 공식 API(선택)**: Meta 개발자 앱에서 직접 발급한 토큰으로 내 게시물의 좋아요·댓글 수와 팔로워 수가 늘었는지 몇 분마다 확인합니다. 프로 계정(비즈니스·크리에이터)이 필요합니다.

## 준비물

- **ClaudeTool 0.4.2 이상**
- **폰 알림 전달을 쓰려면**: 안드로이드 폰, 폰에 설치한 [MacroDroid](https://www.macrodroid.com/)(안드로이드 자동화 앱), 폰에서 Instagram·Threads 알림이 켜져 있을 것. iPhone은 안 됩니다.
- **Meta 공식 API를 쓰려면**: 프로페셔널 계정(비즈니스·크리에이터)과 Meta 개발자 앱에서 직접 발급한 장기 토큰(Instagram용, Threads용 따로). 토큰 발급 절차와 화면은 Meta가 바꿀 수 있으니 Meta의 공식 문서를 따르세요.
  - Instagram: <https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login/get-started> 필요한 권한은 `instagram_business_basic`과 `instagram_business_manage_comments`입니다.
  - Threads: <https://developers.facebook.com/docs/threads/get-started> 필요한 권한은 `threads_basic`, `threads_read_replies`, `threads_manage_insights`입니다.
  - 토큰은 비밀번호처럼 다루세요. 아는 사람은 내 계정의 정보를 읽을 수 있습니다. 아래 예시는 모양만 보이는 가짜 값입니다. `IGAA0000000000000000`

## 설치

### ① 플러그인 zip 가져오기

1. [릴리스](https://github.com/BlackBuddle/claude-tool-page/releases/tag/plugins-2026-10)에서 `sns-notify.zip`을 받습니다. 릴리스 노트의 SHA-256 값과 비교해 보세요.
2. ClaudeTool 설정 창 › 🧩 플러그인 › ＋ 가져오기(.zip)로 그 파일을 고릅니다.
3. 동의 창에 아래 줄이 보이는지 확인하고 설치합니다.
   - 말풍선을 띄워요
   - 로그인 정보(토큰·키)를 이 PC에 암호화해 보관해요
   - Windows 알림을 띄워요
   - 사용자가 누른 링크를 브라우저로 열어요
   - 글을 클립보드에 복사해요
   - `wss://ntfy.sh`
   - `https://ntfy.sh`
   - `https://graph.instagram.com`
   - `https://graph.threads.net`

   앞의 두 주소(`ntfy.sh`)는 폰 알림 전달에 쓰입니다. 알림 글(누가 무엇을 했는지)이 ntfy.sh 서버를 거칩니다(아래 "개인정보"). 뒤의 두 주소(`graph.…`)는 "Meta 공식 API 쓰기"를 켰을 때만 접속합니다. 링크는 말풍선의 [Instagram 열기]·[Threads 열기]·[DM 열기]·[게시물 열기] 버튼을 눌렀을 때만 열립니다. 비밀 칸(토큰)이 있어 "이 플러그인은 그 값을 읽어요"라는 안내도 함께 보입니다.
4. 카드가 "실행 중"이 되면 설정 창에서 다음 중 쓰는 길을 준비합니다. 둘 다 써도 됩니다.
   - 폰 알림 전달: 아래 "폰 연결하기".
   - Meta 공식 API: "Meta 공식 API 쓰기"를 켜고 "Instagram 토큰"·"Threads 토큰" 칸에 발급한 토큰을 넣습니다(쓰는 계정만). 토큰 칸은 비밀 칸이라 저장한 뒤에는 값이 다시 보이지 않고, 앱의 안전 저장소에만 둡니다. 넣으면 곧바로 한 번 확인합니다.

### ② 캐릭터 zip 가져오기(선택)

1. 설정 창 › 🐾 캐릭터 › ⤓ 가져오기(.zip)에서 `choux-desk-pack.zip`을 고르고 "사용하기"를 누릅니다.
2. 이 캐릭터를 편집기에서 열어 동작을 더 넣으려면 캐릭터 편집기 화면의 "동작 한도" 칸을 37 이상(예: 40, 최대 60)으로 올려 주세요(기본은 12개이고, 이 캐릭터는 동작이 36개라 36으로는 새 동작을 더할 수 없습니다). 열기·저장·사용은 올리지 않아도 됩니다.

캐릭터가 없어도 말풍선과 Windows 알림은 옵니다. 다른 캐릭터에는 이 플러그인용 몸짓이 없어서 몸짓만 빠집니다.

### ③ 폰 연결하기(안드로이드, MacroDroid)

1. 설정 창에서 [토픽 만들기]를 누릅니다. `ct-`로 시작하는 무작위 글(**토픽**)이 만들어지고, 곧바로 그 토픽으로 ntfy에 연결합니다. 토픽은 이 알림 길의 비밀번호라서 화면에는 보이지 않고, [토픽 복사]를 눌러야 클립보드에 복사됩니다.
2. 폰의 MacroDroid에서 새 매크로를 만듭니다. 화면의 이름과 위치는 앱 판에 따라 다를 수 있습니다.
   - **트리거**: "알림 수신"(알림이 왔을 때)을 고르고, 앱 목록에서 **Instagram**과 **Threads**만 고릅니다. MacroDroid가 알림 접근 권한을 요구하면 허용해 주세요.
   - **동작**: "HTTP 요청"을 고르고 방식은 **POST**로 합니다.
   - **주소**: `https://ntfy.sh/` 뒤에 복사한 토픽을 붙여 넣습니다. 예: `https://ntfy.sh/ct-00000000000000000000`
   - **본문(내용)**: MacroDroid의 매직 텍스트 목록에서 **앱 이름**, **알림 제목**, **알림 내용** 항목을 차례로 골라 넣고 사이를 `|`(세로 줄)로 나눕니다. 순서는 반드시 `앱 이름|알림 제목|알림 내용`입니다. 항목의 철자는 MacroDroid 판마다 다를 수 있으니 목록에서 고르세요. 알림이 왔을 때 실제로 보내지는 글은 이런 모양입니다.

     `Instagram|Instagram|민수님이 회원님의 사진을 좋아합니다.`
3. 매크로를 켭니다. 폰이 절전 모드에서 MacroDroid를 멈추면 알림이 전달되지 않을 수 있으니, 안드로이드 설정에서 MacroDroid의 배터리 사용을 제한하지 않도록 바꿔 두세요.
4. 잘 되는지 보려면 Instagram 알림을 하나 받아 보세요. 설정 창의 "마지막으로 받은 폰 소식"이 "방금"으로 바뀌고 말풍선이 뜹니다. PC에서 먼저 시험하려면 PowerShell에서 아래 명령을 칩니다(토픽 자리에 내 토픽을 넣으세요).

   `curl.exe -d "Instagram|Instagram|minsu liked your photo." https://ntfy.sh/ct-00000000000000000000`

   이 명령은 PowerShell의 명령 기록에 토픽이 남습니다. 시험한 뒤에는 기록 파일(`(Get-PSReadLineOption).HistorySavePath`가 알려 주는 파일)에서 그 줄을 지우거나, 설정 창에서 [토픽 다시 만들기]로 토픽을 새로 만드세요.

- 앱 이름 칸은 패키지 이름(`com.instagram.android`, Threads는 `com.instagram.barcelona`)이든 표시 이름(`Instagram`, `Threads`)이든 알아봅니다. 못 알아보면 알림 글로 어느 앱인지 판단합니다.
- 토픽을 잃어버렸거나 남에게 알려졌다면 [토픽 다시 만들기] 버튼(두 번 눌러야 합니다)으로 새로 만들고 폰 매크로의 주소도 바꾸세요. 옛 토픽은 더 이상 읽지 않습니다.

### ④ 설정 칸

| 칸 | 기본값 | 뜻 |
|---|---|---|
| ntfy 서버 주소 | `https://ntfy.sh` | 알림 글을 중계하는 서버. https 주소만 됩니다(토픽이 비밀번호라 http면 평문으로 지나가서 막고, 이 PC의 localhost만 예외입니다). 바꾸려면 아래 "자체 ntfy 서버"도 하세요 |
| 폰 알림 전달 쓰기 | 켬 | 끄면 연결하지 않습니다 |
| Meta 공식 API 쓰기 | 끔 | 켜면 토큰 칸으로 Meta를 확인합니다 |
| Instagram 토큰 · Threads 토큰 | (비어 있음) | Meta 개발자 앱에서 발급한 장기 토큰(비밀 칸). 칸을 바꾸면 갱신해 둔 토큰과 비교 기준을 버리고 새로 시작합니다(플러그인이 꺼져 있는 동안 바꿨어도 다음에 켜질 때 알아채고 같게 처리합니다) |
| Meta 확인 간격(분) | 5 | Meta를 다시 확인하는 간격(2~60) |
| 좋아요 알림 · 댓글 알림 · 새 팔로워 알림 · 메시지 알림 · 언급 알림 | 켬 | 종류별로 끄기 |
| Windows 알림도 띄우기 | 켬 | 끄면 말풍선과 펫 몸짓만 |
| 방해 금지 시작·끝(HH:MM) | (비어 있음) | 둘 다 적으면 그 시간에는 알리지 않고 모아 두었다가 끝나면 한 번에 알립니다. `22:00`~`07:00`처럼 자정을 넘겨도 됩니다. 한쪽만 적거나 형식이 틀리면 꺼 두고 설정 창에 이유가 보입니다 |

설정 창 안에는 마지막으로 확인한 시각, 폰 알림 전달의 연결 상태(연결됨·끊김, 언제부터)와 마지막으로 받은 폰 소식의 시각, Instagram·Threads의 읽기 상태와 토큰 남은 날, 최근 소식이 보입니다. 버튼은 [지금 확인]과 [토픽 만들기]·[토픽 복사]·[토픽 다시 만들기]입니다. [지금 확인]은 끊겼으면 다시 연결하고, 열려 있으면 놓친 글을 보충하고, Meta를 켰으면 바로 읽습니다.

## 알림 종류와 펫 동작

| 종류 | 언제 | 말풍선 | 펫 동작(`choux-desk`) |
|---|---|---|---|
| 좋아요(`like`) | 폰 알림에 "좋아합니다"·"liked" 같은 말이 있을 때 / Meta: 게시물의 좋아요가 늘 때 | "[Instagram 좋아요] 민수님이 회원님의 사진을 좋아합니다." · "[Instagram 좋아요] 게시물 좋아요가 3개 늘었어요(총 8개)", [Instagram 열기]·[게시물 열기] | `sns_like`(하트 배지와 반짝임) |
| 댓글(`comment`) | 폰 알림에 "댓글"·"commented"·"replied" 같은 말이 있을 때 / Meta: 새 댓글·답글 | "[Instagram 댓글] 지연님이 회원님의 게시물에 댓글을 남겼습니다: 멋져요" · "[Threads 댓글] @jiyeon: 새 답글입니다" | `sns_comment`(말풍선 배지) |
| 새 팔로워(`follower`) | 폰 알림에 "팔로우"·"started following" 같은 말이 있을 때 / Meta: 팔로워 수가 늘 때 | "[Instagram 새 팔로워] 팔로워가 3명 늘었어요(총 103명)" | `sns_follower`(사람과 더하기 배지와 반짝임) |
| 메시지(`dm`) | 폰 알림에 "메시지"·"message"·"DM"이 있을 때(폰 알림 전달에서만) | "[Instagram 메시지] minsu sent you a message.", [DM 열기] | `sns_dm`(종이비행기 배지) |
| 언급(`mention`) | 폰 알림에 "언급"·"mentioned"·"tagged"가 있을 때(폰 알림 전달에서만) | "[Threads 언급] minsu mentioned you in a thread." | `sns_mention`(@ 배지) |

- 폰 알림 글은 위 표의 순서대로 처음 맞는 말로 종류를 정합니다. 예를 들어 "댓글을 좋아합니다"는 좋아요입니다.
- 종류를 못 가르는 글(광고성 알림 등)은 "[Instagram 소식] …" 말풍선(toast)으로만 알립니다. 신호·Windows 알림·버튼이 없고 펫 몸짓도 없습니다.
- 말풍선의 버튼: Instagram은 [Instagram 열기]로 `https://www.instagram.com/`을, Threads는 [Threads 열기]로 `https://www.threads.net/`을, 메시지는 [DM 열기]로 `https://www.instagram.com/direct/inbox/`를 엽니다. Meta 소식은 그 게시물의 [게시물 열기]입니다. 어느 앱인지 모르는 글에는 버튼이 없습니다.
- 같은 글은 2분 안에 한 번만 알립니다. 같은 사람이 비슷한 글을 연달아 보내도 내용이 같으면 한 번입니다.
- Meta는 **수가 늘었을 때만** 알립니다. 처음 확인은 지금 수를 기준으로 저장만 하고 알리지 않으며, 줄어든 것·내가 단 댓글은 알리지 않습니다.
- 소식이 한꺼번에 몰리면 말풍선을 목록 하나로 합쳐 보여 줍니다.

## 개인정보

- **알림 글이 ntfy 서버를 거칩니다.** 폰이 보낸 글(누가 어떤 댓글을 남겼는지, DM이면 내용 일부까지)이 ntfy.sh를 지나 이 PC로 옵니다. ntfy.sh는 공개 서비스이고 서버는 글을 잠시(기본 12시간) 보관합니다.
- **토픽을 아는 사람은 누구나 그 글을 읽고 보낼 수 있습니다.** 토픽은 무작위 20글자라 추측하기는 어렵지만, 새어 나갔다면 [토픽 다시 만들기]로 바꾸세요.
- DM 알림의 내용(메시지 글 일부)도 이 길로 갑니다. 메시지를 서버에 보내고 싶지 않다면 Instagram 앱의 알림 설정에서 메시지 알림을 끄세요. 좋아요·팔로우 같은 알림의 문구는 알림 내용에 들어 있어서, 내용을 빼면 종류를 알아볼 수 없습니다.
- 서버를 믿지 못하겠다면 아래 "자체 ntfy 서버"로 내 서버를 쓰세요.
- [토픽 복사]는 토픽을 클립보드에 넣습니다. Windows의 클립보드 기록이 켜져 있으면 기록에 남을 수 있으니, 폰 매크로에 붙여 넣은 뒤 다른 글을 복사하거나 기록을 지우세요. 복사는 분당 10번까지만 됩니다.
- 토픽과 갱신한 Meta 토큰은 앱의 안전 저장소에만 두고, 저장 파일·앱 로그·말풍선·설정 창에는 싣지 않습니다. 앱이 연결 실패 오류의 주소를 서버 이름까지만 남깁니다(ClaudeTool 0.4.3부터). 0.4.2에서는 연결이 실패할 때 토픽이 plugins.log·설정 창 마지막 오류에 남을 수 있으니, 로그를 남에게 보내기 전에 지우거나 [토픽 다시 만들기]를 하세요.
- Meta를 쓰면 `graph.instagram.com`·`graph.threads.net`에 토큰과 함께 요청합니다. 받은 댓글 글은 말풍선에만 쓰고 저장하지 않으며, 저장하는 것은 게시물·댓글 번호와 숫자뿐입니다.

## 자체 ntfy 서버

내 서버를 쓰면 알림 글이 공개 서비스를 거치지 않습니다([ntfy 설치 안내](https://docs.ntfy.sh/install/)). 서버 주소를 바꾸려면 두 곳을 맞춰야 합니다.

1. 플러그인 설정의 "ntfy 서버 주소"를 `https://ntfy.example.com`처럼 바꿉니다(끝에 `/`는 있든 없든 됩니다). 폰 매크로의 주소도 그 서버로 바꿉니다. 주소는 https만 받습니다. http 서버는 토픽(이 알림 길의 비밀번호)이 인터넷을 평문으로 지나가서 막고, 이 PC 안의 `localhost`·`127.0.0.1`·`[::1]`만 예외입니다.
2. 설치된 플러그인은 `plugin.json`에 적은 주소로만 접속할 수 있어서, 받은 `sns-notify.zip`을 풀어 안의 `plugin.json`을 메모장 등으로 열고 `network` 목록에 `"wss://ntfy.example.com"`과 `"https://ntfy.example.com"` 두 항목을 쉼표로 이어 더합니다. 그다음 풀린 폴더 안의 파일 전부(`plugin.json`, `main.js`, `ui` 폴더 등)를 선택해 zip으로 다시 묶어 가져옵니다. 최상위에 `plugin.json`이 오게 묶어야 합니다(PowerShell이면 풀린 폴더의 부모 폴더에서 `Compress-Archive -Path .\sns-notify\* -DestinationPath .\sns-notify-own.zip`). 같은 플러그인의 업데이트로 처리되고 설정은 이어받으며, 동의 창에 새 주소가 보입니다. 포트가 기본(443)이 아니면 `wss://ntfy.example.com:8443`처럼 포트까지 적어야 열립니다. 직접 고친 zip에는 서명도 검사도 없으니 본인이 고친 것만 가져오고, 남이 고쳐서 준 zip은 쓰지 마세요.

로그인이 필요한(비공개) ntfy 서버는 지원하지 않습니다.

## 한계

- **안드로이드만** 됩니다. 폰 알림 전달은 MacroDroid가 필요하고, iPhone에서는 쓸 수 없습니다.
- 폰 알림 전달은 알림 글의 말투(한국어·영어)로 종류를 가르기 때문에 알림 문구가 바뀌면 "소식"으로만 알릴 수 있습니다. 다른 언어의 알림은 지원하지 않습니다. 글 안의 말(댓글 내용 등)이 종류 판단에 섞일 수 있습니다.
- 폰과 PC가 모두 켜져 있고 인터넷이 이어져 있어야 합니다. PC에서 연결이 끊기면 30초마다 다시 연결하고, 그동안 쌓인 글은 다시 열릴 때 보충합니다. 연결이 열려 있는데 90초 넘게 아무 신호(서버가 약 45초마다 보내는 연결 확인 신호 포함)가 없으면 반쯤 끊긴 것으로 보고 바로 다시 연결해 놓친 글을 보충합니다(절전에서 깨어난 뒤 등). 보충은 최근 6시간 안의 글 10건까지만 알립니다(앱을 오래 꺼 뒀다 켜도 옛 소식이 쏟아지지 않게). 서버가 글을 보관하는 시간(기본 12시간)이 지난 글은 가져올 수 없습니다.
- 처음 연결할 때는 보충하지 않습니다(그 전에 온 글은 알리지 않습니다).
- **Meta 공식 API는 프로페셔널 계정과 내가 직접 만든 Meta 개발자 앱이 필요합니다.** 개인 계정의 DM·개별 좋아요는 폰 알림 전달로만 받을 수 있고, Threads의 언급은 Meta의 앱 검수 전에는 내 앱으로 읽을 수 없어 폰 알림 전달로만 받습니다.
- Meta는 확인 간격(기본 5분)마다 수를 비교합니다. 그 사이에 늘었다 줄어든 것은 놓치고, 알림은 실제 시각보다 최대 간격만큼 늦을 수 있습니다. 한 번에 알리는 새 댓글은 게시물마다 5개까지, Instagram은 댓글이 늘어난 게시물 3개까지만 읽습니다. 응답에 좋아요·댓글 수가 없으면(권한이 부족한 경우 등) 그 항목은 조용히 건너뜁니다.
- 처음 보는 게시물은 그 순간의 수를 기준으로 저장만 하므로, 올린 지 몇 분 안에 받은 좋아요는 알리지 않습니다.
- Meta 토큰은 60일 뒤 만료됩니다. 만료 7일 전부터 자동으로 갱신해 앱의 안전 저장소에 두고(발급 24시간 안이라 갱신이 거절되면 하루 뒤 다시 시도합니다), 갱신한 토큰이 있으면 그것을 씁니다(설정 칸의 토큰이 바뀌면 버립니다). 60일 동안 이 플러그인이 꺼져 있었다면 토큰이 영구 만료되니 새로 발급해 넣어야 합니다. 설정 창에 "토큰 약 N일 남음"이 보입니다.
- 폰 알림 전달과 Meta를 함께 켜면 같은 일이 두 번 알려질 수 있습니다.
- **Windows 알림은 분당 6개, 말풍선은 분당 10개까지만** 갑니다. 넘으면 말풍선은 "N건 더 있어요" 목록으로 합쳐 보여 줍니다.

## 문제 해결

| 증상 | 이유와 해결 |
|---|---|
| 설정 창에 "폰 알림 전달: 토픽이 아직 없어요" | [토픽 만들기]를 누르세요 |
| "폰 알림 전달: 연결이 끊겼어요. 30초마다 다시 연결해요" | 인터넷이 끊겼거나 ntfy 서버에 닿지 않습니다. 자체 서버를 쓴다면 `plugin.json`의 `network`에 `wss`·`https` 주소(포트 포함)를 더했는지 보세요. 앱 로그(`logs\plugins.log`)에 "플러그인의 WebSocket을 막았어요"가 있으면 이 경우입니다 |
| "ntfy 서버 주소가 올바르지 않아요" | "ntfy 서버 주소"가 `https` 주소가 아닙니다(http는 토픽이 평문으로 지나가서 이 PC의 localhost만 됩니다). 사용자 이름·비밀번호·물음표 없이 적어 주세요 |
| 연결됨인데 알림이 안 와요 | ① 설정 창의 "마지막으로 받은 폰 소식"이 바뀌는지 보세요. 안 바뀌면 글이 서버에 안 오는 겁니다 ② 폰 매크로가 켜져 있는지, MacroDroid의 알림 접근 권한과 배터리 제한 해제 ③ 매크로 주소의 토픽이 정확한지(복사해 붙여 넣으세요) ④ 본문이 `앱 이름|알림 제목|알림 내용` 모양인지 ⑤ 위 PowerShell 명령으로 PC에서 시험해 보세요 |
| 글은 받았는데 "[Instagram 소식] …" toast로만 와요 | 알림 문구에서 좋아요·댓글·팔로우·메시지·언급을 알아보지 못한 겁니다. 알려진 말은 위 "알림 종류" 표에 있습니다 |
| 같은 알림이 한 번만 와요 | 같은 내용은 2분 안에 한 번만 알립니다 |
| 켜자마자 옛 소식이 몇 개 와요 | 앱이 꺼져 있던 동안(또는 끊긴 동안) 서버에 쌓인 글을 보충한 것입니다. 최근 6시간·10건까지만 옵니다 |
| "Instagram 토큰이 거절됐어요(만료됐거나 틀려요)" | 토큰이 틀렸거나 만료·폐기됐습니다. Meta 개발자 앱에서 새로 발급해 설정에 다시 넣으세요. 한 번만 말풍선으로 알리고 설정 창에는 계속 보입니다. 고치면 곧바로 다시 읽고 안내가 사라집니다 |
| "…응답을 읽지 못했어요(HTTP 400)" | 계정이 프로페셔널 계정이 아니거나 앱에 필요한 권한이 없습니다. 위 "준비물"의 권한 이름을 확인하세요 |
| Meta가 한참 조용해요 | Meta가 호출 한도를 알려 오면 15분 쉬었다가 다시 읽습니다. 알림은 없습니다 |
| 같은 소식이 두 번 와요 | 폰 알림 전달과 Meta를 함께 켠 경우입니다. 한쪽을 끄세요 |
| [토픽 복사]를 눌렀는데 복사가 안 돼요 | 클립보드 쓰기는 분당 10번까지입니다. 잠시 뒤 다시 누르세요 |
| 토픽이 남에게 알려졌어요 | [토픽 다시 만들기] 버튼(두 번 눌러 확인)으로 새로 만들고, 폰 매크로의 주소를 새 토픽으로 바꾸세요 |
| 알림이 안 와요(말풍선·Windows 알림 모두) | ① 종류를 끄지 않았는지 ② 방해 금지 시간이 아닌지(설정 창에 모인 소식 수가 보입니다) ③ 펫을 숨겨 두지 않았는지(숨기면 말풍선은 못 뜨고 Windows 알림만 옵니다) ④ Windows의 "방해 금지"·집중 지원이 알림을 막고 있지 않은지 확인하세요 |
