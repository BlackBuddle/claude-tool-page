# Steam 알림(steam-notify) 안내

Steam 친구가 접속하거나 게임을 시작할 때, 그리고 위시리스트에 있는 게임이 할인에 들어갈 때 펫이 말풍선과 Windows 알림으로 알려 주는 플러그인입니다. Steam에 로그인하지 않고, 공개된 정보를 읽기만 합니다.

## 준비물

- **ClaudeTool 0.4.2 이상**
- **Steam Web API 키.** 친구 상태를 읽는 데 씁니다. 키를 아는 사람은 내 이름으로 Steam의 공개 정보를 읽을 수 있으니 비밀번호처럼 다루세요. 아래 예시는 모양만 보이는 가짜 값입니다.

  `00000000000000000000000000000000`
- **내 SteamID64.** 프로필을 가리키는 17자리 숫자입니다. 예시: `76561190000000000`
- **공개로 바꾼 프로필 설정.** 친구 목록과 위시리스트가 공개여야 읽힙니다.

### Web API 키 받기

1. 브라우저에서 `https://steamcommunity.com/dev/apikey`에 들어가 Steam 계정으로 로그인합니다.
2. "도메인 이름"에는 개인용이니 아무 값(예: `localhost`)이나 적고, 약관을 읽어 본 뒤 동의하고 등록합니다.
3. 나타나는 32자리 키를 복사합니다. 키가 새어 나갔다면 같은 페이지에서 폐기하고 새로 받을 수 있고, 그러면 옛 키는 쓸 수 없게 됩니다.

구매 이력이 없는 "제한된 계정"은 키를 받을 수 없을 수 있습니다. 그때는 이 플러그인을 쓸 수 없습니다.

### SteamID64 찾기

1. Steam 프로필 페이지를 열고 주소창을 봅니다.
2. 주소가 `https://steamcommunity.com/profiles/76561190000000000`처럼 숫자 17자리로 끝나면 그 숫자가 SteamID64입니다.
3. 주소가 `https://steamcommunity.com/id/내별명`처럼 별명으로 끝나면 숫자가 아닙니다. 이때는 프로필 주소를 넣으면 SteamID64를 알려 주는 조회 사이트(예: `steamid.io`)에서 "steamID64" 값을 찾으세요.

### 프로필 공개 설정

1. Steam에서 프로필 › 프로필 편집 › 개인 정보 설정으로 갑니다.
2. "친구 목록"을 **공개**로 둡니다. 비공개이면 Steam이 401을 돌려줘서 친구 알림을 받을 수 없습니다.
3. 위시리스트를 알리려면 "게임 세부 정보"를 **공개**로 둡니다. 비공개이면 위시리스트가 비어 보입니다.
4. 바꾼 설정이 반영되기까지 몇 분 걸릴 수 있습니다.

## 설치

### ① 플러그인 zip 가져오기

1. [릴리스](https://github.com/BlackBuddle/claude-tool-page/releases/tag/plugins-2026-10)에서 `steam-notify.zip`을 받습니다. 릴리스 노트의 SHA-256 값과 비교해 보세요.
2. ClaudeTool 설정 창 › 🧩 플러그인 › ＋ 가져오기(.zip)로 그 파일을 고릅니다.
3. 동의 창에 아래 줄이 보이는지 확인하고 설치합니다.
   - 말풍선을 띄워요
   - Windows 알림을 띄워요
   - 사용자가 누른 링크를 브라우저로 열어요
   - `https://api.steampowered.com`
   - `https://store.steampowered.com`

   이 두 주소가 플러그인이 접속하는 곳의 전부입니다. 링크는 말풍선의 [프로필 열기]·[상점 열기] 버튼을 눌렀을 때만 열립니다.
4. 카드가 "실행 중"이 되면 상세 칸의 "Steam Web API 키" 칸에 복사한 키를, "SteamID64" 칸에 17자리 숫자를 넣습니다. 키 칸은 비밀 칸이라 저장한 뒤에는 값이 다시 보이지 않고, 앱의 안전 저장소에만 둡니다. 둘을 넣으면 곧바로 한 번 확인합니다.

### ② 캐릭터 zip 가져오기(선택)

1. 설정 창 › 🐾 캐릭터 › ⤓ 가져오기(.zip)에서 `choux-desk-pack.zip`을 고르고 "사용하기"를 누릅니다.
2. 편집기에서 동작을 더 넣으려면 캐릭터 편집기 화면의 "동작 한도" 칸을 37 이상(예: 40, 최대 60)으로 올려 주세요(기본은 12개이고, 이 캐릭터는 동작이 36개라 36으로는 새 동작을 더할 수 없습니다). 열기·저장·사용은 올리지 않아도 됩니다.

캐릭터가 없어도 말풍선과 Windows 알림은 옵니다. 다른 캐릭터에는 이 플러그인용 몸짓이 없어서 몸짓만 빠집니다.

### ③ 설정 칸

| 칸 | 기본값 | 뜻 |
|---|---|---|
| Steam Web API 키 | (비어 있음) | 위에서 복사한 32자리 키 |
| SteamID64(17자리 숫자) | (비어 있음) | 내 SteamID64. 숫자만, 공백 없이 |
| 친구 확인 간격(분) | 2 | 친구 상태를 다시 읽는 간격(1~30) |
| 세일 확인 간격(시간) | 6 | 위시리스트 할인을 다시 보는 간격(1~24) |
| 친구 접속 알림 · 친구 게임 시작 알림 · 위시리스트 세일 알림 | 켬 | 종류별로 끄기 |
| Windows 알림도 띄우기 | 켬 | 끄면 말풍선과 펫 몸짓만 |
| 방해 금지 시작·끝(HH:MM) | (비어 있음) | 둘 다 적으면 그 시간에는 알리지 않고 모아 두었다가 끝나면 한 번에 알립니다. `22:00`~`07:00`처럼 자정을 넘겨도 됩니다. 한쪽만 적거나 형식이 틀리면 꺼 두고 설정 창에 이유가 보입니다 |

설정 창 안에는 마지막으로 확인한 시각, 보고 있는 친구 수, 위시리스트 수와 할인 중인 수, 최근 소식이 보입니다. [지금 확인]은 친구 상태를, [세일 확인]은 위시리스트 할인을 바로 다시 확인합니다.

## 알림 종류와 펫 동작

| 종류 | 언제 | 말풍선 | 펫 동작(`choux-desk`) |
|---|---|---|---|
| 친구 접속(`friend-online`) | 친구가 오프라인에서 접속 상태(온라인·자리 비움·다른 용무 중 등)가 될 때 | "Alice님이 접속했어요", [프로필 열기] | `st_friend_online`(사람 배지) |
| 친구 게임 시작(`friend-playing`) | 게임을 하지 않던 친구가 게임을 시작할 때 | "Bob님이 Counter-Strike 2 플레이를 시작했어요", [프로필 열기]·[상점 열기] | `st_friend_playing`(게임 컨트롤러 배지) |
| 위시리스트 세일(`sale`) | 위시리스트의 게임이 할인에 들어갈 때, 게임마다 한 번 | "게임 이름 50% 할인 · ₩10,000 (정가 ₩20,000)", [상점 열기] | `st_sale`(퍼센트 배지와 반짝임) |

- 친구 접속·게임 시작은 플러그인을 처음 켠 직후의 첫 확인에서 지금 상태를 기준으로 저장만 하고 알리지 않습니다. 이미 접속해 있던 친구가 한꺼번에 알림으로 쏟아지지 않습니다. 위시리스트는 달라서, 처음 확인할 때 이미 할인 중인 게임도 한 번 알립니다(여섯 개를 넘으면 할인율 큰 여섯 개와 요약 한 건).
- 친구 한 명이 접속과 동시에 게임을 시작했다면 "게임 시작" 한 건만 알립니다. "친구 게임 시작 알림"을 꺼 두었다면 "접속"으로 알립니다.
- 접속을 끊거나, 게임을 끝내거나, 다른 게임으로 바꾸는 것은 알리지 않습니다.
- 같은 게임의 할인은 한 번만 알립니다. 할인이 끝난 것을 확인한 뒤에 다시 할인하면 새로 알립니다.
- 한 번에 새 할인이 많이 생기면(여섯 개를 넘으면) 할인율이 큰 여섯 개만 따로 알리고 나머지는 "위시리스트 게임 N개가 더 할인 중이에요" 한 건으로 알립니다.
- 소식이 한꺼번에 몰리면 말풍선을 목록 하나로 합쳐 보여 줍니다.

## 한계

- 친구는 500명까지, 위시리스트는 앞쪽 300개까지 봅니다.
- 접속·게임 시작은 확인하는 순간의 상태를 비교해서 알립니다. 확인 간격(기본 2분) 사이에 접속했다 끊은 친구는 알림이 없을 수 있고, 알림은 실제 시각보다 최대 간격만큼 늦을 수 있습니다.
- Steam에서 "오프라인으로 보이기"를 켠 친구는 오프라인으로 보이므로 접속 알림이 오지 않습니다.
- 앱이 꺼져 있던 동안의 변화는 알리지 않습니다. 다시 켰을 때 마지막 확인이 확인 간격의 세 배(최소 15분)보다 오래전이면 지금 상태를 새 기준으로 삼고 첫 확인에서는 알리지 않습니다.
- 위시리스트 할인은 Steam 상점의 비공식 주소로 가격을 읽습니다. Steam이 예고 없이 바꾸거나 요청이 많다며 막을 수 있습니다. 막히면(429) 간격을 늘려 자동으로 다시 시도하고, 친구 알림에는 영향이 없습니다. 확인 간격(기본 6시간) 사이에 끝나는 짧은 할인은 놓칠 수 있습니다.
- 위시리스트를 가져오는 주소는 Steam이 응답 모양을 자세히 밝히지 않았습니다. 모양이 달라지면 "위시리스트를 읽지 못했어요"라고 표시하고 세일 알림만 멈추며, 친구 알림은 계속됩니다.
- 가격은 한국 상점(원화) 기준입니다. 게임 이름은 새 할인 여섯 건까지만 상점에서 하나씩 가져옵니다. 가져오지 못하면 "앱 12345"처럼 번호로 알립니다.
- Steam 밖에서 추가한 게임을 친구가 하면 게임 이름은 알리지만 [상점 열기] 버튼은 없습니다.
- 키는 요청 주소에만 쓰고 앱 로그·저장 파일·말풍선에 남기지 않습니다.

## 문제 해결

| 증상 | 이유와 해결 |
|---|---|
| 설정 창에 "설정에서 Steam Web API 키와 SteamID64를 넣어 주세요" | 키나 SteamID64 칸이 비어 있습니다. 위 "준비물"대로 넣어 주세요 |
| "SteamID64는 17자리 숫자예요" | 별명(`/id/…` 뒤의 글)이나 자릿수가 틀린 값을 넣었습니다. 위 "SteamID64 찾기"대로 17자리 숫자를 넣으세요 |
| "설정을 확인해 주세요(키나 토큰이 거절됐어요, HTTP 401/403)"와 "친구 목록은 프로필에서 공개로 두어야 읽을 수 있어요" | 키가 틀렸거나 폐기됐거나, 친구 목록이 비공개입니다(401). 키를 다시 확인하고 프로필 개인 정보 설정의 "친구 목록"을 공개로 바꾸세요. 한 번만 말풍선으로 알리고 설정 창에는 계속 보입니다 |
| "잠시 뒤 다시 시도해요(HTTP 429/5xx)"나 "서버에 연결하지 못했어요" | Steam이 바쁘거나 요청이 많다며 막았거나 인터넷이 끊겼습니다. 알림 없이 간격을 늘려 자동으로 다시 시도하고, 되돌아오면 지웁니다 |
| "위시리스트를 읽지 못했어요" | Steam이 위시리스트 응답 모양을 바꿨을 수 있습니다. 친구 알림은 계속 됩니다 |
| "위시리스트가 비었거나 공개가 아니에요" | 위시리스트에 게임이 없거나 "게임 세부 정보"가 비공개입니다. 위 "프로필 공개 설정"을 확인하세요 |
| 앱 로그(`logs\plugins.log`)에 "요청이 거절됐어요" | 요청한 서버가 `api.steampowered.com`·`store.steampowered.com`이 아닙니다. 이 두 곳의 주소만 쓸 수 있습니다 |
| 알림이 안 와요 | ① 종류를 끄지 않았는지 ② 방해 금지 시간이 아닌지(설정 창에 모인 소식 수가 보입니다) ③ 펫을 숨겨 두지 않았는지(숨기면 말풍선은 못 뜨고 Windows 알림만 옵니다) ④ Windows의 "방해 금지"·집중 지원이 알림을 막고 있지 않은지 ⑤ 친구가 "오프라인으로 보이기"를 켜지 않았는지 확인하세요 |
| 켜자마자 친구 알림이 없어요 | 처음 확인과 오래 꺼 뒀다 켠 뒤의 첫 확인은 지금 상태를 기준으로 저장만 합니다. 그 다음 확인부터 달라진 것을 알립니다 |
| 세일이 떴는데 알림이 없어요 | 확인 간격(기본 6시간) 안에 끝났거나, 이미 알린 게임입니다. [세일 확인]을 눌러 보세요. 위시리스트가 공개인지도 확인하세요 |
