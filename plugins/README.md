# ClaudeTool 플러그인 묶음 안내

ClaudeTool의 펫이 캘린더·날씨·유튜브·GitHub·Steam·VS Code·메일·SNS 소식을 말풍선과 Windows 알림으로 알려 주게 하는 예제 플러그인 8개와, 소식마다 다른 몸짓을 보여 주는 캐릭터 `choux-desk`입니다. 플러그인은 서로 독립이라 필요한 것만 설치하면 됩니다.

## 한눈에 보기

| 플러그인 | 하는 일 | 필요한 것 | 안내서 |
|---|---|---|---|
| 캘린더 알림 `cal-notify` | 일정이 곧 시작할 때·시작할 때·아침마다 알림 | 구글·아웃룩 캘린더의 iCal 비공개 주소 | [cal-notify.md](cal-notify.md) |
| 날씨 알림 `weather-notify` | 비·초미세먼지·더위·추위, 아침 날씨 요약 | 도시 이름(계정·키 없음) | [weather-notify.md](weather-notify.md) |
| 유튜브 검색·새 영상 `yt-search` | 펫에게 검색을 시키고, 구독 채널의 새 영상을 알림 | YouTube Data API 키 | [yt-search.md](yt-search.md) |
| GitHub 알림 `github-notify` | 리뷰 요청·멘션·CI 실패·병합 알림 | GitHub 토큰(classic) | [github-notify.md](github-notify.md) |
| Steam 알림 `steam-notify` | 친구 접속·게임 시작, 위시리스트 할인 | Steam Web API 키, SteamID64 | [steam-notify.md](steam-notify.md) |
| IDE 코딩 참견 `ide-buddy` | 저장·오류·테스트·오래 쉼에 한 줄 참견 | VS Code 1.90 이상과 확장(.vsix) | [ide-buddy.md](ide-buddy.md) |
| 메일 알림 `mail-notify` | 새 메일·중요 메일·하루 요약 | Gmail 또는 Outlook 연결 준비 | [mail-notify.md](mail-notify.md) |
| SNS 알림 `sns-notify` | Instagram·Threads의 좋아요·댓글·팔로워·DM·언급 | 안드로이드 폰과 MacroDroid, 또는 Meta 개발자 앱 | [sns-notify.md](sns-notify.md) |

캐릭터는 [choux-desk.md](choux-desk.md)에서 알림마다 어떤 몸짓이 나오는지 볼 수 있습니다.

## 공통 설치

모든 플러그인이 같은 순서로 설치됩니다. 서비스마다 다른 준비물(키·토큰·주소)을 받는 방법은 각 안내서에 있습니다.

1. **받기.** [플러그인 묶음 릴리스](https://github.com/BlackBuddle/claude-tool-page/releases/tag/plugins-2026-10)에서 플러그인 zip(`<플러그인 이름>.zip`)과 캐릭터 zip(`choux-desk-pack.zip`)을 받습니다. IDE 코딩 참견을 쓰려면 VS Code 확장(`ide-buddy-vscode-1.0.0.vsix`)도 받습니다. 받은 파일은 릴리스 노트의 SHA-256 값과 비교해 보세요(PowerShell에서 `Get-FileHash .\<파일 이름> -Algorithm SHA256`).
2. **플러그인 가져오기.** ClaudeTool 설정 창 › 🧩 플러그인 › ＋ 가져오기(.zip)에서 zip을 고릅니다. 동의 창에 이 플러그인이 쓰는 권한과 접속하는 인터넷 주소가 줄마다 나옵니다. 안내서의 목록과 같은지 확인하고 설치하세요. 목록에 없는 주소나 권한이 보이면 설치하지 마세요.
3. **캐릭터 가져오기(선택).** 설정 창 › 🐾 캐릭터 › ⤓ 가져오기(.zip)에서 `choux-desk-pack.zip`을 고르고 "사용하기"를 누릅니다. 한 번만 가져오면 8개 플러그인이 모두 씁니다. 캐릭터가 없어도 말풍선과 Windows 알림은 오고, 몸짓만 빠집니다.
4. **설정 칸 채우기.** 카드가 "실행 중"이 되면 카드를 눌러 상세 칸을 채웁니다. 키·토큰·주소처럼 남에게 보이면 안 되는 칸은 저장한 뒤 값이 다시 보이지 않고, 앱의 안전 저장소에만 둡니다.

필요한 앱 버전은 **ClaudeTool 0.4.2 이상**입니다.

### 공통으로 알아 둘 것

- 방해 금지 시간을 정해 두면(`22:00`~`07:00`처럼 자정을 넘겨도 됩니다) 그 동안의 소식을 모아 두었다가 끝나면 한 번에 알려 줍니다. 한쪽만 적거나 형식이 틀리면 꺼 두고 설정 창에 이유가 보입니다.
- 앱이 띄울 수 있는 말풍선은 분당 10개, Windows 알림은 분당 6개입니다. 넘치는 소식은 잃지 않고 잠시 뒤 "N건 더" 말풍선 하나로 모아 알립니다.
- 말풍선의 [열기] 같은 버튼은 사용자가 눌렀을 때만 브라우저를 엽니다. 플러그인이 혼자 링크를 열지는 않습니다.
- 플러그인은 동의 창에 보인 인터넷 주소로만 접속합니다. 그 밖의 주소는 앱이 막고 앱 로그(`logs\plugins.log`)에 남깁니다.
- 키·토큰은 앱 로그, 말풍선, 설정 창 어디에도 적히지 않습니다(앱이 연결 실패 오류에 든 인터넷 주소를 서버 이름까지만 남기고 뒷부분을 지웁니다. ClaudeTool 0.4.3부터이고, 0.4.2에서는 연결이 실패할 때 주소 속 값이 `logs\plugins.log`에 남을 수 있습니다). 새어 나갔다고 의심되면 해당 서비스에서 키를 다시 발급받고 설정 칸을 바꾸세요.

## 확인표

설치한 뒤 제대로 동작하는지 플러그인마다 한 가지씩 확인하는 표입니다. 서비스에 실제 소식이 올 때까지 기다리지 않고 바로 볼 수 있는 것으로 골랐습니다. 하나라도 안 되면 그 안내서의 "문제 해결" 표를 보세요.

- [ ] **cal-notify** 주소를 붙여 넣고 설정 창의 [지금 확인]을 누르면 마지막으로 확인한 시각과 다음 일정이 보인다.
- [ ] **weather-notify** 도시를 적고 [지금 확인]을 누르면 설정 창에 오늘 날씨 요약이 보인다.
- [ ] **yt-search** 설정 창 안 화면의 "검색 창 열기"로 연 창에서 검색하면 펫이 검색 몸짓을 하고, 말풍선에 결과와 [열기] 버튼이 나온다.
- [ ] **github-notify** 토큰을 저장하면 설정 창에 마지막 확인 시각과 GitHub 요청 한도 남은 수가 보인다.
- [ ] **steam-notify** 키와 SteamID64를 저장하고 [지금 확인]을 누르면 설정 창에 보고 있는 친구 수가 보인다.
- [ ] **ide-buddy** 설정 창에 "VS Code 확장 … 연결됨"이 보이고, 빨간 줄(오류)이 있는 파일을 저장하면 펫이 오류 참견을 한다.
- [ ] **mail-notify** 연결 칸을 채우면 설정 창에 계정별 연결 상태와 마지막 확인 시각이 보인다(처음 확인은 기존 메일을 알리지 않고 그 수만 보여 줍니다).
- [ ] **sns-notify** 설정 창에서 [토픽 만들기]를 누르면 [토픽 복사] 버튼이 생기고, 복사한 토픽을 안내서의 시험 명령(`curl.exe`)에 넣어 글을 하나 보내면 말풍선이 뜬다.
